# 📚 Kitap Okuma Takipçisi v1.0

Python ile geliştirilmiş basit bir terminal uygulamasıdır. Kullanıcıların okudukları kitapları eklemesine, listelemesine ve okuma ilerlemelerini takip etmesine olanak sağlar.

## ✨ Özellikler

- ➕ Kitap ekleme
- 📖 Kitapları listeleme
- 📊 Okunan sayfaya göre tamamlanma yüzdesini hesaplama
- 🖥️ Basit ve kullanımı kolay terminal arayüzü

## 🛠️ Kullanılan Teknolojiler

- Python 3

## 🚀 Nasıl Çalıştırılır?

1. Bu depoyu bilgisayarına indir veya klonla.
2. Terminali proje klasöründe aç.
3. Aşağıdaki komutu çalıştır:

```bash
python main.py
```

## 📷 Örnek Menü

```text
=== Kitap Takip Sistemi ===

1. Kitap ekle
2. Kitapları listele
3. Okunan sayfaları güncelle
4. Çıkış yap
```

## 🎯 Gelecek Güncellemeler

- Verileri JSON dosyasına kaydetme
- Kitap silme
- Kitap düzenleme
- Kitap arama
- Okuma istatistikleri
- Kitap puanlama ve not ekleme
