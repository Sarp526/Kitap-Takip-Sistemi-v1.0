# 📚 Kitap Okuma Takipçisi v1.0

Python ile geliştirilen basit bir terminal uygulamasıdır. Kitap eklemenizi, kitaplarınızı görüntülemenizi ve okuma ilerlemenizi takip etmenizi sağlar.

## Özellikler

- 📖 Yeni kitap ekleme
- 📚 Eklenen kitapları listeleme
- 📄 Kitapların toplam sayfa sayılarını görüntüleme
- 📊 Okunan sayfa sayısına göre tamamlanma yüzdesini hesaplama
- 🖥️ Terminal tabanlı kullanıcı menüsü
- ❌ Uygulamadan güvenli bir şekilde çıkış yapma
